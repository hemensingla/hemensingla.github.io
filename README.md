## Das Projekt: KI-Workflow für die Jobsuche

Seit September 2026 nutze ich Claude für meine Suche nach einer Werkstudentenstelle:

1. **Finden:** Claude liest Job-Alerts aus Gmail und sucht mit Firecrawl auf Jobportalen.
2. **Prüfen:** Firecrawl holt den Text der Originalanzeige, Claude vergleicht ihn mit meinen Regeln und vergibt einen Score von 1 bis 10.
3. **Sammeln:** Jede Stelle landet in einem Google Sheet, sortiert nach Score.
4. **Besprechen und bewerben:** Vor jedem Anschreiben bespricht Claude die Stelle mit mir. Prüfen und abschicken tue ich selbst.

Die ausführliche Beschreibung, inklusive der Probleme, die ich unterwegs gelöst habe, steht auf der [Workflow-Seite](https://hemensingla.github.io/workflow.html).

## Technik

- Reines HTML, CSS und JavaScript, ohne Framework
- Gebaut mit Claude
- Gehostet mit GitHub Pages
